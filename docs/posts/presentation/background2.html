##Maryland’s typically a young defense. But since Michael Locksley’s took over, there’s been a drastic shift over year-to-year of wherether the Terps are playing freshman or not. They’ve played a ton in some years (2019,2021 and 2025) and barely played some in other years. I think this just shows the overall instablity during the Locksley tenure. There’s just a lack of cohesion and overall plan on how many freshman they’re going to play. They’ve tried to be more veteran heavy in recent years, as you can see, but then this season, they relied on a ton of freshman this year. Sidney Stewart, Zahir Mathis and Messiah Dellhome all played signifcant snaps and were expected to be the best players on the defense.

# Years and corresponding opponents
years <- 2015:2025
opponents <- c(
  "bostoncollege",  # 2015
  "alabama",        # 2016
  "alabama",        # 2017
  "missst",         # 2018
  "osu",            # 2019
  "marshall",       # 2020
  "wisconsin",      # 2021
  "airforce",       # 2022
  "michigan",       # 2023
  "indiana",        # 2024
  "osu"             # 2025
)

summary_list <- list()

for (i in seq_along(years)) {
  y   <- years[i]
  opp <- opponents[i]
  
  md_df  <- get(paste0("md", y))
  opp_df <- get(paste0(opp, y))
  
  summary_list[[i]] <- tibble(
    year = factor(y),
    team = c("Maryland", opp),
    value = c(
      mean(md_df$snap_counts_defense,  na.rm = TRUE),
      mean(opp_df$snap_counts_defense, na.rm = TRUE)
    )
  )
}

summary <- bind_rows(summary_list)

# Set custom colors: Maryland red, all others gray
summary$color <- ifelse(summary$team == "Maryland", "Maryland", "Opponent")

ggplot(summary, aes(x = year, y = value, fill = color)) +
  geom_col(position = position_dodge(width = 0.8), width = 0.7) +
  scale_fill_manual(
    values = c(
      "Maryland" = "red",
      "Opponent" = "gray80"
    )
  ) +
  labs(
    x = "Season",
    y = "Freshman Defensive Snap Count",
    title = "Maryland's defense typically plays way more freshman than the No. 1 defense in the country",
    fill = ""
  ) +
  theme_minimal() +
  theme(
    legend.position = "none",
    axis.text.x = element_text(angle = 45, hjust = 1)
  )

##But if Maryland wants to reach the level that its trying to achieve, it needs to either bring in more talented freshman, or get older. The Terps, compared to the No. 1 defense in the nation over the years, played more freshman than that unit seven times since 2015. While some of these teams are substantially better than the Terps have been historically, it’s a good barometer to look too when considering how Maryland’s defense can get better. A number of those units, including Michigan, Ohio State and Indiana all came from the Big Ten.
